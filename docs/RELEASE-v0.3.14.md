# Compás 0.3.14 · Colecciones para tu rincón

Tres colecciones con doce piezas ilustradas, basadas en la propuesta visual aprobada. Completar un producto o compromiso concede una elección; las tareas no conceden piezas. Cada registro concede una sola elección, incluso si se reabre. Las elecciones pendientes y piezas se conservan en el respaldo privado y se excluyen de los reportes. Mis colecciones permite elegir, colocar y retirar una pieza sin perderla. Las invitaciones pueden omitirse o desactivarse.

Se mantienen los adornos básicos disponibles desde el principio. La colección usa ilustraciones generadas para la propuesta; las representaciones de teorías son metáforas visuales. No se añaden citas ni atribuciones académicas. Se requiere 0.3.14 o posterior para conservar esta metadata al volver a guardar un respaldo.
